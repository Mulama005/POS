# POS System — Tech Accessories & Repairs Shop

Electronics retail POS for the Kenyan market. Monorepo containing both the frontend and backend.

## Structure

```
pos-system/
├── client/     React + Vite + TypeScript frontend (PWA, offline-first)
└── server/     ASP.NET Core backend (Clean Architecture: Domain / Application / Infrastructure / Api)
```
